# ClownMart 🤡

Полнофункциональный демо‑сайт интернет‑магазина клоунских аксессуаров.

## Возможности
- Каталог на **120 товаров** (более 100 объектов) с поиском, фильтрацией по категории и сортировкой.
- Избранное и корзина с изменением количества.
- Сохранение корзины и избранного в `localStorage`.
- Полная эмуляция checkout: контакты → доставка → оплата.
- На финальном шаге оформление намеренно блокируется сообщением о технических работах.

## Запуск локально в Docker
```bash
docker compose up --build -d
```
Откройте: http://localhost:8080

Остановка:
```bash
docker compose down
```
